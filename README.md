# SyncHub

A multi-tenant SaaS platform that enables organizations to manage teams, projects, tasks, and collaboration within isolated workspaces.

## Features

* Multi-tenant organization management
* Role-based access control (Owner, Admin, Manager, Member)
* Team management
* Project management
* Task assignment and tracking
* Project and team announcements
* Performance reports and analytics
* Secure workspace isolation

## Roles

### Platform Owner

* View platform statistics
* Monitor organizations, users, projects, and tasks

### Organization Admin

* Manage members
* Generate reports
* Manage organizations

### Manager

* Create teams and projects
* Assign tasks
* Manage members
* Publish announcements

### Member

* View projects and tasks
* Update task status
* Access announcements

## Tech Stack

* **Frontend:** React, Tailwind CSS
* **Backend:** Node.js, Express.js
* **Database:** PostgreSQL
* **Authentication:** JWT

## Project Goal

Provide organizations with a centralized workspace for collaboration while ensuring complete data isolation between tenants.
